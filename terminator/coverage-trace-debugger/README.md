
# Coverage Trace Debugger

Coverage Trace ist ein Debugger, der die Basic Blocks einer Programmausführung in Ausführungsreihenfolge ohne Wiederholung abspeichert. Ist eine Programmausführung definiert durch die Abfolge von Basic Blocks A, C, C, B, B, C, A, so speichert Coverage Trace die Liste A, C, B ab.

Hash enthält ein einfaches Hilfsprogramm.

Beide Programme werden von TERMINATOR verwendet.
